# Audit hardening report — 2026-09-10

Scope: reliability, cancellation semantics, deployment secret handling, existing regression/integration gates, dependency audit, and production Docker build.

## Confirmed issue 1: half-open search probe can become permanently stuck

A request cancelled while the circuit breaker is in `HALF_OPEN` propagated `asyncio.CancelledError` past the normal `Exception` handler. The probe slot stayed occupied, which could prevent all later probes for that backend for the process lifetime.

Fix: cancellation now releases the half-open probe slot without counting caller cancellation as a backend failure, then re-raises cancellation.

Regression: `CircuitBreakerCancellationTests.test_cancelled_half_open_probe_releases_probe_slot`.

## Confirmed issue 2: synced `.env` could be group/world readable

When `.env` did not yet exist, `scripts/sync_env.py` inherited permissions from `.env.example` (normally `0644`). It also returned early for unchanged content without tightening an existing permissive `.env`.

Fix: new `.env` files are written `0600`; existing files have group/other and execute bits removed while preserving stricter owner permissions. Permission-only repair does not rewrite file contents.

Regressions: `tests/test_sync_env_permissions.py` covers new-file and unchanged-existing-file paths.

## Verification

Both issues were reproduced with failing tests before their fixes. The final branch push passed the repository's full `Audit checks` workflow on Python 3.11 and 3.12, including lint, compile checks, targeted Crawl4AI/URL tests, the full regression/integration suite, dependency audit, Docker Compose validation, and production Docker image build where configured.

## Non-blocking observations

The audit also noted process-lifetime in-memory maps for per-user rate limiting, per-conversation memory, and chat locks. Each entry is individually bounded or small, but the number of keys is not capped. This is worth future operational hardening for very high-churn deployments; it was not classified as a release-blocking defect for the current allowlisted-group deployment model.
